# Changelog

Changes to the listings and plugins in this repository. The Roar AI MCP server itself is hosted at `https://cloud.roar-ai.com/mcp`, so new tools reach every assistant without a release here.

## 2026-11-13 · ChatGPT plugin 1.0.5

- ChatGPT starts by saying what Roar AI can do and asking what you want to build. There is no account setup step first: it saves your business name from your answer.
- New starter prompt: "What can I do with Roar AI?"
- ChatGPT can read the files of an app that is already online and change them, so it no longer asks for a GitHub repository or a ZIP file.
- You can ask for a monthly limit on what an app spends on AI.
- A new skill covers building an app, changing one, giving it AI and limiting its spend.

## 2026-11-11 · ChatGPT plugin 1.0.4

- After setting up your account, ChatGPT offers to start on a website for your business and asks only what it does. Before, it showed a list and asked what you wanted to do first.
- The other first jobs are still listed, so you can pick something else.

## 2026-11-10 · ChatGPT plugin 1.0.3

- New starter prompts:
  - "Make a website for my business with Roar AI"
  - "Build an AI chatbot for my business with Roar AI"
  - "Put my app online with Roar AI"
- The get-started skill offers the same first jobs, asks only what each one needs, and finishes with a live link.
- Once an app is live, ChatGPT mentions what else it can have: AI, a database, your own domain, or private access.

## 2026-11-09 · ChatGPT plugin 1.0.2

- ChatGPT can put an app online straight from the files it writes, with no GitHub repository needed, and update it later.
- Apps already on GitHub deploy as before.

## 2026-11-08 · ChatGPT plugin 1.0.1

- Starter prompts that work on a brand-new account.
- A get-started skill that sets up your account and shows what Roar AI can do.

## 2026-10-26

- The README links the Roar AI plugin in ChatGPT's plugin directory.

## 2026-10-20 · MCP Registry listing 1.0.1

- The description now leads with deploying the apps you build.

## 2026-10-19

- The ChatGPT plugin's category is `Developer Tools`.
- The `create_key` review case expects a one-time setup code rather than the key itself.

## 2026-10-16 · First release

- Connect guides for Claude, ChatGPT, Codex, Cursor and VS Code.
- A Claude Code plugin, the ChatGPT plugin package, and the MCP Registry listing.
